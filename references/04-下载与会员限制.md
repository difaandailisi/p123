# 04 · 下载与会员限制（如实报告）

这是 123 云盘最容易被忽略、也最容易踩坑的地方。**本技能不破解、不绕过官方限制，只如实探测并报告。**

## Web 端下载被拦截（核心结论）

即使用 API 拿到了文件信息、甚至拿到了直链，**Web 端下载仍可能被官方策略直接拦下**：

```
POST /file/download/traffic/check
{ "fids": [<FileId>] }

→ {
    "code":0,
    "data": {
      "isBlocked": true,            // ← 被拦
      "isTrafficExceeded": false,   // 流量没超
      "originalRemainTraffic": 8440000276,  // 剩余 ~7.8GB
      "clientFileSize": 765805824,
      "originalFileSize": 1531611648
    }
  }
```

关键矛盾：**流量没超（`isTrafficExceeded=false`），剩余还有 7.8GB，但 `isBlocked=true`**。
也就是说，这不是"流量包用完"，而是**账号级别的 Web 下载策略限制**，需要开 VIP 才解。

点下载按钮时，页面弹出的是**会员购买框**（"VIP 连续包月 ¥9，不限下载流量"），而不是真正的下载。

## 分享提取流量

生成分享链接本身能成功，但对方"提取"需要分享方的流量包：

```
GET /share/traffic-info
→ { "data": { "shareTrafficBalanceTip": "您的分享提取流量包不足，请充值后重试。" } }
```

默认账号分享提取流量为 0。

## 给用户的务实建议

1. **自己要装/要用**：用 123 云盘 **Windows / 手机客户端**下载，客户端策略与 Web 不同，免费额度通常每天 10GB，够用。
2. **给别人**：在 123 云盘里生成分享链接即可；若对方提取失败，提示其充值分享流量包，或你这边买流量包。
3. **开 VIP**：¥9/月，之后 Web 端也能直接拉。
4. **本技能定位**：把"浏览、整理、搜索、上传、转存"自动化做好；下载受限时明确告知原因与替代方案，而不是假装能下。

> 所有限制均来自官方策略，随政策变动。本技能不做任何绕过登录/付费/限速/风控/DRM 的尝试。
