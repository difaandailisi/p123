# 03 · 上传与秒传

123 云盘上传分两条路：**秒传**（零字节，推荐）和**浏览器实际上传**（大文件/未命中秒传时）。

## 秒传原理

123 的服务端按文件内容 MD5 去重。上传前先算本地文件 MD5，带上 `etag` 请求预检：

```
POST /file/upload_request
{ "driveId":0, "etag":"<文件MD5>", "fileName":"xxx.exe", "parentFileId":0,
  "size":<字节>, "type":0, "duplicate":2, "RequestSource":null }
```

返回：

```json
{ "code":0, "data": {
    "Reuse": true,            // true=服务端已有相同 MD5，直接挂载，无需传字节
    "StorageNode":"m42",
    "S3KeyFlag":"1820002404-0",
    "SliceSize":"67108864",
    "Info": { "FileId": 95602873, "FileName":"xxx.exe", "Size":..., "Etag":"..." }
} }
```

- `Reuse: true` → **文件已挂到你的网盘**，占用你的空间、可正常下载/分享，**但没传任何字节**。适合官方安装包、热门资源（已有大量用户上传过）。
- `Reuse: false` → 服务端没有这个 MD5，必须真实上传字节（走 S3 分片）。本技能此时回退到浏览器上传。

> 实测：Android Studio 官方安装包（1.43GB）命中秒传，MD5 `71595bab9da7b13d748564f6e113dfb0` 与服务端 `Etag` 完全一致。

## 浏览器实际上传（未命中秒传时）

`duplicate:2` 表示"若同名则提示"。用 Playwright 驱动 Web 上传：

```
1. 打开 https://yun.123pan.cn/ ，注入登录态
2. 点「上传」→ 通过 input[type=file] 选文件
3. 若出现「同名文件」对话框，点「覆盖」
4. 等待完成
```

对应 `scripts/p123.py upload <路径>`（秒传未命中自动走浏览器）与 `browser_upload()`。

## 字段提醒

| 字段 | 说明 |
|---|---|
| `data.Info.FileId` | **真实 FileId**（新建/上传后取这里，别取顶层 `data.FileId`） |
| `data.Reuse` | 是否秒传命中 |
| `SliceSize` | 分片大小（64MB），真实分片上传时每块这么大 |
| `duplicate` | `2`=同名提示；真实上传场景可按需调整 |

## 命令

```bash
# 秒传优先；命中则 0 字节完成，未命中自动浏览器上传
python3 scripts/p123.py upload ./android-studio-rabbit2-windows.exe

# 强制走浏览器上传（跳过秒传尝试）
python3 scripts/p123.py upload ./big.iso --force-browser
```

## 转存他人分享

```
POST /share/save
{ "shareKey":"<分享密钥>", "sharePwd":"", "fileIdList":[...], "parentFileId":0 }
```

分享密钥从分享链接 `https://www.123pan.com/s/xxxx` 的 `xxxx` 提取。转存免费，但对方分享的"提取流量"取决于分享方；本技能只负责把内容存到你自己的网盘。
