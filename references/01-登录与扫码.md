# 01 · 登录与扫码

123 云盘的登录在自动化/无头环境下有两个坑，本技能只走"扫码"这一条稳的路。

## 域名澄清（重要）

| 用途 | 域名 | 备注 |
|---|---|---|
| 业务主站 | `yun.123pan.cn` | 文件管理、列表、上传落地页 |
| **登录页** | `user.123pan.cn` | **真实登录域名是 `.cn`**，不是 `.com` |
| 分享/旧入口 | `www.123pan.com` / `123684/865/912.com` | 分享链接常见；但 `www` 下的登录接口反复 404 |

> 经验：最开始用 `www.123pan.com` 登录，所有接口都 404。切到 `user.123pan.cn/centerlogin` 立刻通。

## 为什么不用手机号 + 验证码登录

手机号登录在无头/自动化浏览器里会被**阿里云滑块验证**（"请按住滑块，拖动到最右边"）拦截。实测：

- 用 Playwright 模拟 `mouse.move` 分段拖拽，滑块位置正确但服务端判定失败（风控识别了非人工轨迹）。
- 阿里云新版本滑块用 `pointerEvents` 遮挡 + 轨道宽度校验，JS 注入 `pointerEvents:none` 也过不了。

**结论：无头环境下手机号登录不可行，一律走扫码。** 扫码不需要过滑块。

## 扫码登录流程（`scripts/login_qr.py`）

```
1. Playwright 打开 https://user.123pan.cn/centerlogin
2. 定位页面里的二维码元素（img/canvas，近似正方形 120~420px）
3. 裁剪并保存为 123云盘登录二维码.png（device_scale_factor=2 放大，方便手机扫）
4. 轮询登录态：URL 不再含 centerlogin，或 cookie/localStorage 出现 authorToken/sso-token
5. 保存 storage_state 到 ~/.p123/state.json（p123.py 默认读取）
```

用户侧操作：
1. 用**手机 123 云盘 App** 扫二维码，或微信扫。
2. 手机点"确认登录"。
3. 脚本自动检测到并完成保存。

二维码约 2~5 分钟失效；超时未登录脚本退出码 1，重新运行即可。

## 登录态里有什么

`state.json`（Playwright storage_state）包含两类凭证：

- **`localStorage.authorToken`**：JWT，正是 API 鉴权用的 `Authorization: Bearer <token>`。
  - 注意：`user.123pan.cn` 域下的 `authorToken` 值可能被 JSON 包裹成 `"eyJ..."`（带首尾引号），解析时要 `strip('"')`；`yun.123pan.cn` 域下是干净的。取最长那个 JWT 即可。
- **`cookies`**：`sso-token`（有效期到 2027 年）、`acw_tc` 等，浏览器上传时由 Playwright 自动带上。

> 登录态等同账号权限，按密码保管。用完可在 123 云盘「设置 → 设备管理」踢掉本次登录。
