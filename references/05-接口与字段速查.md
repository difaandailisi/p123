# 05 · 接口与字段速查

所有接口基地址：`https://api.123278.com/b/api`

通用请求头：

```
Authorization: Bearer <localStorage.authorToken>
platform: web
app-version: 3
Origin: https://yun.123pan.cn
Referer: https://yun.123pan.cn/
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... Chrome/131.0.0.0 Safari/537.36
```

通用说明：机房网络访问 `api.123278.com` 偶发 SSL 断连（EOF），客户端已内置 4 次重试。

| 方法 | 路径 | 用途 | 关键参数 | 返回要点 |
|---|---|---|---|---|
| GET | `/user/info` | 账号信息 | — | `data.UID / Nickname / Passport` |
| GET | `/file/list/new` | 列目录 / 搜索 | `parentFileId`、`SearchData`、`next` 翻页 | `data.InfoList[]`、`data.Next` |
| POST | `/file/upload_request` | 新建文件夹 / 上传预检（秒传） | `type=1`文件夹 / `etag`=MD5 / `duplicate=2` | `data.Reuse`、`data.Info.FileId` |
| POST | `/file/delete` | 删除（→回收站） | `fileId` | `code:7301` 视为成功 |
| POST | `/file/download/traffic/check` | 下载流量预检 | `fids:[id]` | `data.isBlocked` |
| POST | `/share/save` | 转存他人分享 | `shareKey`、`fileIdList`、`parentFileId` | — |
| GET | `/share/traffic-info` | 分享提取流量余额 | — | `data.shareTrafficBalanceTip` |
| POST | `/file/info` | 文件详情 | `fileIdList:[id]` | `data.InfoList[]` |

## 关键字段释义

| 字段 | 含义 / 坑 |
|---|---|
| `FileId` | 文件/夹唯一 ID。新建/上传后**取 `data.Info.FileId`**，顶层 `data.FileId` 可能为 0 |
| `Type` | `1`=文件夹，`0`=文件 |
| `Etag` | 文件 MD5，上传秒传比对用 |
| `Reuse` | `true`=服务端已有同 MD5，秒传命中，无需传字节 |
| `isBlocked` | Web 下载是否被官方策略拦截（即使流量充足也可能 true） |
| `Next` | 翻页游标，`"-1"`/`"0"` 表示到底 |

## 登录态文件结构（`~/.p123/state.json`）

```jsonc
{
  "cookies": [ { "name":"sso-token", "value":"eyJ..." }, ... ],
  "origins": [
    { "origin":"https://yun.123pan.cn",
      "localStorage":[ { "name":"authorToken", "value":"eyJ..." } ] },
    { "origin":"https://user.123pan.cn",
      "localStorage":[ { "name":"authorToken", "value":"\"eyJ...\"" } ] }  // 注意：可能被 JSON 引号包裹
  ]
}
```

解析 token 时：`user.123pan.cn` 域的 `authorToken` 值可能带首尾 `"`，需 `strip('"')`；取最长 JWT 即可。
